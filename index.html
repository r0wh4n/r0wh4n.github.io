Ping

A shared room where AI coding agents work together. Put Claude Code, Codex and Cursor in one room. They share project context, talk to each other, and see commits, pull requests and CI results in one timeline.

  • Rooms are scoped to a directory, so one team’s room isn’t delivered into another team’s project.
  • A live view of every agent room over a single WebSocket.
  • One-command install as a Claude Code plugin.
  • Also a consumer chat app: @handle sign-up with no phone number, end-to-end encrypted DMs, groups and calls.

Open source · macOS

Klipvault

An encrypted clipboard manager for the menu bar. Every item is sealed with AES-256-GCM before it reaches disk. It flags 13 kinds of secrets, like API keys, JWTs and card numbers, and can lock any single clip behind Touch ID. No dependencies, and no network code at all. It went from v1.0 to v1.1 in a week.

$ brew install --cask r0wh4n/tap/klipvault

Resume Tailor

Tailors a résumé to a job posting without inventing anything. A writer model rewrites your real experience in the posting’s language. A screener model grades the result requirement by requirement, and the two loop until the score stops improving. Anything your résumé can’t back up comes back as a gap you can fill in yourself. Built in about two days.

Security research · private

Nebula

Finds exploitable vulnerabilities in source code and proves them. Nebula hunts for critical and high-severity bugs across web apps, CLIs, libraries and services. It only confirms a finding once it has a working proof of concept, which sharply cuts the false positives that pattern-matching SAST tools produce. Each finding comes CVSS-scored and ready to triage.

Static analysis · PoC generation · CVSS

A voice assistant that runs your Mac. Say the wake word and it transcribes on-device with Whisper, plans with an LLM, and controls apps through AppleScript and in-browser JavaScript. It acts while you’re still talking, and asks for a spoken yes before anything risky.

How I work

AI agents do much of the typing. I own what ships.

For an early team, that means a working prototype in days, and infrastructure, monitoring and security handled by the same person who builds the product.

Several agents in parallel, one reviewer

I run Claude Code, Codex and Cursor on separate tasks at the same time and review the diffs before they merge. Changes that touch production ship with tests and a rollback path.

I build the tooling too

Ping’s agent rooms exist because I wanted assistants from different vendors to share one context. Resume Tailor went from first file to open-source release in about two days.

Speed with guardrails

Secret scanning, least-privilege CI and branch protection are part of how I ship. At CARS24 I also added guardrails to the internal LLM gateway.

If I join your team

  1. Week 1

    Ship something real. A fix or a feature in production is the fastest way I know to learn a codebase.

  2. Weeks 2–3

    Make releases routine. CI/CD, infrastructure as code, preview environments and one-click rollback.

  3. Week 4

    Know when it breaks. Dashboards, alerts that fire only for real problems, and uptime checks on every public endpoint.

  4. Ongoing

    A security baseline. SSO, secret scanning, least-privilege access and zero trust for internal tools, sized to your stage.
