# rohan pandey · portfolio

Personal site: frontend, backend, AI, DevOps, SRE and security, one engineer.

One static `index.html`, no build step, no framework, no trackers. Open it in a browser to preview.

- `index.html`: the whole site (inline CSS and a few lines of JS)
- `Resume.pdf`: linked résumé
- `og.png`: 1200×630 link-preview image

Deploy anywhere that serves static files (Vercel, Cloudflare Pages, Netlify, GitHub Pages).
Live at https://r0wh4n.github.io. If the domain changes, update `og:url`, `og:image` and `canonical` in `index.html`.
